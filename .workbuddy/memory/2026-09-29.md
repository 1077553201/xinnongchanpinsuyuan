## 本轮踩过的坑（重要）

1. **npm 首次安装被打断**：`esbuild` postinstall 报 `EBUSY` 导致 `@esbuild/win32-x64`、`@rollup/rollup-win32-x64-msvc` 两个平台二进制缺失，构建报 MODULE_NOT_FOUND。解决：删 `node_modules` + `package-lock.json` 后**干净重装**即可（`--no-save` 补装会被下次 npm 清理掉，不可取）。
2. **8080 端口在沙箱内绑定报 `EACCES`**：离开沙箱实测 **8080 可正常绑定**，并非系统保留端口（此前判断有误，已更正 README）。预览 mock 服务仍固定用 **8090**，以免与后端 8080 冲突；通过 `vite --mode mock` + `vite.config.ts` 中按 mode 决定代理目标（不依赖 env 文件解析，实测 `loadEnv` 读取正常但内联环境变量传不进配置）。
3. **无头 Chrome 截图视口不一致**：`--window-size=430` 截图时布局视口实际约 489px，导致右侧被裁，误判为 CSS 溢出。正确做法是用 CDP `Emulation.setDeviceMetricsOverride` + `Page.captureScreenshot(captureBeyondViewport)`。实测 390px 下 `scrollWidth === clientWidth`，无溢出。
4. **公共页栅格必须用容器查询**：`.trace` 限宽 520px，若用视口媒体查询，桌面端（视口 1400px）会误入 4 列/3 列而挤窄折行。改为 `container-type: inline-size` + `@container`。
5. **`StagePlaceholder` 标题读错来源**：读的是 props（路由未传），应从 `route.meta` 取。
6. **`.gitignore` 的 `.env.*` 会连带忽略 `frontend/.env.*`**：已加例外放行 `.env.development` / `.env.production` / `.env.mock`。
