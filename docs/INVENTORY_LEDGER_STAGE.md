# 库存入出库台账阶段记录

更新时间：2026-10-21。承接 [采收与包装阶段](HARVEST_PACKING_STAGE.md)，本阶段将真实包装来源接入仓库、入库、出库与库存损耗，继续推进 [生产到销售规划](PRODUCTION_TO_SALES_AGENT_PLAN.md) 阶段 2。

## 操作入口与流程

管理台新增“库存台账”（`/admin/inventory`），选择来源种植周期和包装批次查看；“采收与包装”的包装记录也提供直接入口。

1. **登记仓库：** 填写所属机构、唯一编码、名称、实际位置及说明。仓库登记不自动接收包装，不凭包装表里的存放位置推断库存。
2. **登记实际入库：** 选择与包装同机构的仓库，填写完整包装件数、实际时间、现场人员及办理说明。允许分次、分仓接收，整批累计入库不能超过实际包装件数。
3. **登记实际出库：** 按指定仓库办理，填写实际去向或领用用途及现场信息。只能扣减该仓该批在库件数，不能借用其他仓的库存。当前为普通实际出库，尚未关联销售订单或运单。
4. **登记库存损耗：** 单独填写件数和原因，扣减对应仓库存；损耗与出库分别统计，不通过改写入库数量掩盖损耗。

当前只处理完整包装，例如箱、袋。件数须为正整数，单件净重沿用不可变的包装来源，系统据此计算每笔净重。拆箱称重、部分包装损坏和散装销售不在本阶段范围。

## 数量、时间与来源

每批保留“实际包装件数 = 尚未入库 + 累计入库”；库存保留“当前在库 = 累计入库 − 实际出库 − 库存损耗”。分仓分别核对，全批再汇总，净重采用十进制定点数计算。

入库上限按历史累计入库计算，出库或损耗不会重新释放“可入库名额”；退回不能冒充新入库。包装、等级、采收、周期和地块的关联保持不变；种植结束后仍可办理库存，不阻止地块换季。

实际办理时间不能早于包装或晚于当前时间，同仓同批也不能早于最近一笔流水；同秒流水按记录顺序办理。当前没有迟到单据重算历史库存流程，遇到倒填日期须先核对，不让新流水造成历史负库存。

## 权限与可靠性

- 管理员可跨机构查看和办理；生产人员仅能办理本机构，只读人员只能查看。仓库和包装必须同机构；页面与后续 Agent 共用业务服务校验。
- 事务按地块、周期、包装来源加锁，入出库与损耗并发时仍检查最新累计量及分仓余量。业务记录与审计同事务保存。
- 每笔库存使用确认键和内容摘要防重复，同一请求重试返回原单，修改内容不能沿用原确认键。现场办理人与登录录入人分别留档。
- 仓库编码唯一，重复登记不能创建同编码仓库；当前没有仓库编辑、停用或确认键重放接口。
- 接口已关闭将小数自动截断为整数的行为；包含 `1.5` 等小数的整数字段直接返回格式错误。这也保护既有整数字段不被静默截断，前端整数字段提交正常整数不受影响。

页面显示每周期最近最多 200 批包装，尚未全部入库优先；每批展示最近 200 条流水，汇总与余量始终覆盖全部记录。仓库档案和分仓余量按当前权限查询。
