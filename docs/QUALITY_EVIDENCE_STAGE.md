# 质检版本存证与报告替代实施记录

更新：2026-10-25。继续批次 B 的 NEXT-03、04、08，并补充 NEXT-07 的报告更正关系；不代表全部业务更正已完成。

## 使用入口

采收与包装 → 查看来源与办理 → 采收或包装质检报告。报告卡片提供“质检证据存证”和“查看 / 关联替代关系”。

- 逐码存证：输入完整包装码，预览报告、原件 SHA-256、来源与版本摘要，勾选核对后提交。只有曾公开的报告和已完成生产来源存证的适用包装码可办理；采收样本不代表所有关联包装码均已存证。
- 状态变化：撤回、附件公开权限或已公开替代关系发生变化时，生成新证据版本；旧版、原记载结论及前序摘要保留。每份报告与每个码最多 20 版。
- 恢复回执：允许核对最近冻结版本；先读实际链事件，再判断是否可发送。未知交易保留 `UNCERTAIN`，不盲目重发；明确失败回执或禁用链写入可经确认恢复。
- 替代办理：先撤回原报告，再登记相同机构及完全相同采收/包装范围的较新草稿，预览双方资料摘要并确认关联。一次只能有一个前件和后件，不允许分叉或回环。关联不会自动公开新报告。

## 证据与公开边界

新增 `QUALITY_REPORT_EVIDENCE_V1`，复用合约 `QUALITY_TEST` 事件；无需重新部署合约。快照绑定具体码、原生产来源摘要、报告资料及文件摘要、当时公开/撤回状态和允许公开的替代关系。提交前校验私有原件字节，网络调用在短数据库事务之外执行。

公众逐版读取实际链记录，核对身份、事件类型、时间、摘要和前序版本。当前事实与最近冻结版不同，当前结果为未验证；历史已验证版本仍保留。其他报告、其他码不继承结果。原生产与流转快照不覆盖。

替代关系仅在双方均曾公开后展示；内部原因、人员及原文件名不公开。历史存证不绕过当前附件下载权限。摘要一致证明记录一致性，不证明检测机构身份、报告真实性或每件实物质量；替代关系为经营方关联，不冒充检测机构正式更正。
