# 逐件拒收、退回与隔离处置

实施日期：2026-10-26。对应 `NEXT-07` 的拒收异常首批，业务更正与召回仍未全部完成。

## 业务入口与范围

- 侧栏及库存页签增加“退回与隔离”。销售出库的逐件拒收包装码可直接进入来源核对；只存在运输收货汇总、未明确逐件拒收时不能建单。
- 每单绑定原出库和一个完整包装码，固定一件，继承原包装单位与净重，不能重复建单或自行修改数量。
- 仓库页单独显示隔离保管合计并链接本仓明细；普通库存与隔离保管分开，不把不同包装单位直接相加。隔离合计不随状态、包装码或分页筛选改变。

## 状态与留档规则

| 操作 | 前置状态 | 结果 |
| --- | --- | --- |
| 登记处置单 | 原单品明确拒收且无处置单 | 待处置 |
| 退回发运 | 待处置 | 退回在途 |
| 隔离收货 | 待处置、退回在途 | 隔离保管，必须确认同机构仓库与隔离位置 |
| 实际报损 | 隔离保管 | 已报损处置，不再计入隔离保管 |
| 追加更正说明 | 任意状态 | 引用原登记 #0 或已有历史版本，状态和数量不变 |

退回发运不是隔离收货的强制前置：已确认实物直接收到时可以登记隔离收货。实际发生时间不能早于原运输拒收发生时间或最近实际操作，也不能晚于当前时间。更正说明使用当前留档时间，不阻止随后补记较早发生的实际操作。

写入保留实际办理人、登记账号、发生/留档时间、说明及参考编号。原来源、每步内容和前序摘要冻结，当前派生状态必须与完整历史一致；每单最多 100 条事件。提交采用版本摘要核对及确认标识，重复提交相同内容不重复执行，修改内容必须重新核对。

本阶段不写普通库存流水、不重新增加可售数量、不变更订单收货事实、不自动退款或提交链交易。处置报损仅结清隔离保管，不能重复扣减已经销售出库的普通库存。

## 公众展示与证据

公众页仅显示处置状态、版本、摘要、操作类型和时间。实际办理人、内部原因、隔离位置、参考单据等不公开。

有处置单时，其公开摘要纳入本件当前流转事实；已有流转快照不会被改写，新事实须通过既有流转版本流程另行预览、确认和核验。不把本地处置摘要称为已上链。无处置单的包装不增加空字段，保持既有流转事实结构。
