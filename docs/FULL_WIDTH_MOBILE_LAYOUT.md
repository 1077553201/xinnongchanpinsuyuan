# 全宽布局与移动导航调整

更新时间：2026-10-21。本轮暂停生产到销售的新业务推进，整理现有改造并完善公共页面布局；设备管理与绑定数据的问题仍保留在 [待优化清单](OPTIMIZATION_BACKLOG.md)。

## 界面调整

- 桌面管理台取消 1180px 居中上限，采用固定宽度侧栏和占满剩余空间的内容区；侧栏、页头及业务内容使用统一边距和起点。
- 页头统一高度，账号过长时省略显示，侧栏按可视高度滚动。预留页面滚动条空间，减少长短页面切换时的左右位移；业务内容按实际长度自然滚动。
- 900px 及以下隐藏桌面侧栏，右上角按钮打开右侧导航抽屉，取代顶部横排导航。外观切换、账号和退出入口位于抽屉内。
- 抽屉支持关闭按钮、Esc、点击遮罩、选择其他页面后关闭；切回桌面尺寸也关闭并恢复背景滚动。使用原生模态对话框约束键盘焦点，保留减弱动效适配。
- 手机端减小面板内边距，主要操作保留至少 44px 点击高度；宽表格在各自容器内横向滚动，避免撑宽整页。晨光绿与柔光玻璃主题继续保留。

## 外部设备访问

Vite 开发服务默认监听 `0.0.0.0:5173`，固定端口；预览服务监听 `0.0.0.0:4173`。已有带 `--host 127.0.0.1` 的启动命令会覆盖配置，需停止该前端进程后改用 `npm run dev`。本次运行中的前端已调整监听地址。

同一网络使用开发电脑实际 IP，例如本次有线地址 `http://192.168.1.181:5173` 或 Wi-Fi 地址 `http://192.168.0.187:5173`；地址随网络环境变化，以本机为准。`0.0.0.0` 本身不是访问域名。API 通过前端代理，后端无需另行对手机开放端口。

本轮未修改系统防火墙、路由或公网映射。其他设备仍需具备到开发电脑的网络连通性；本机通过局域网 IP 的请求不能代替真实手机或公网验收。
