# 前端第 6 阶段：交易追踪与整体验收

日期：2026-10-20。

## 交付

- `/admin/chain` 实现真实交易列表：业务类型、业务 ID、链状态及返回条数筛选；独立详情查询，展示交易哈希、区块、合约、摘要、调用账户、提交/确认时间及关联业务入口。
- 新增交易 GET 列表与详情 API。列表 SQL 使用绑定参数，最多 500 条；ID 非正数和未知状态被拒绝。无交易重发按钮，不把查询条数当作总数。
- AI 页从工程骨架改为明确的未启用页面；登录页移除「已有认证」暗示和固定演示码入口。AI Provider、账号权限不属于已实现能力。
- 补充根目录 README 与 `scripts/Start-Backend.ps1`，统一 `.env` 加载，定位 Maven，支持 MQTT 开关及只检查模式。

## 验证与状态

- 真实交易类型/业务 ID 筛选返回预期记录，详情含实际哈希和区块；非法业务 ID 返回 400。390px 页面无横向溢出。
- 产品、批次、单品、事件、公众查询、IoT、NFC 和链追踪组成真实操作闭环，分别记录于前面阶段文档。
- 第 2/3/5 阶段保留的 QA 记录共产生 12 次链交易，区块从最初 10 到 22。测试仅操作标记明确的 QA 记录；未删除链上、链下证据。
- 最终前端 27 项状态测试、后端 34 项测试及生产构建通过；启动脚本 `-CheckOnly` 通过且未启动重复服务。9 个实际页面的 390px 布局复核无横向溢出、无浏览器运行异常或 Vue 警告；14 项最终只读接口检查通过，包含不存在设备返回空列表和交易状态/条数过滤。二维码检查验证了本地渲染和打印样式，未验证实体打印机或物理 NFC 芯片。
