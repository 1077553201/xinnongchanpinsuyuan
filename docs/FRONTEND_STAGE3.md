# 前端第 3 阶段：单品码、二维码与溯源事件

日期：2026-10-20。

## 能力

- `/admin/items` 已实现单品搜索、批次/上链状态筛选、本地分页和详情；批次台账可直接跳转关联单品。
- 为生产中批次生成 1–100 个单品码，显示每个码的实际存证状态；批量请求使用较长超时，结果不明时阻止直接重发。
- 选中单品后，在浏览器本地生成二维码，支持预览、修改手机可达的前端地址及批量打印。二维码不依赖第三方图片服务。打印样式仅包含所选标签；未验证实体打印机。
- 详情页录入 11 类事件、北京时间、地点、操作人和说明，显示已有事件及摘要，直接进入公众查询。
- 后端拦截已关闭/召回批次生成和非法数量；事件类型及长度校验，显式接收 `yyyy-MM-dd HH:mm:ss`；事件保存响应返回完成后的真实链状态。

## 验证

- 前端 26 项测试、类型检查及生产构建通过；后端 27 项测试通过。
- 6 项真实浏览器/API检查通过：生成两个唯一单品码，渲染两个二维码，拒绝危险协议地址，模拟打印媒体样式；录入采收事件，独立读取 FISCO 核对事件摘要；公众页展示新记录；手机列表不溢出；非法数量及关闭批次被拒绝。
- 保留 QA 批次 `QA-S3-1792508887496`（ID 3），属于测试产品 ID 1。单品 ID 1、2；单品 ID 2 有一条联调采收事件（ID 1）。均为联调数据。
- 本阶段 4 次本地链交易：批次注册、两次单品绑定、一次事件追加；区块从 14 增至 18。无删除或修改其他记录。

## 边界

当前单品列表的筛选/分页在浏览器本地完成。没有单品状态任意编辑接口、事件删除或交易重试接口。批量生成不是服务器全局幂等操作，提交结果不明时须核对列表；前端不会自动重发。手机扫描需要实际可达的前端地址和网络，不能使用手机自身的 `127.0.0.1`；当前开发服务器只监听本机，开放局域网访问须另行配置。
