# 前端第 2 阶段：产品与批次管理

日期：2026-10-20。

## 页面能力

入口 `/admin/products`，沿用晨光玻璃设计，产品与批次在同一台账切换。

- 产品：按名称、编码、品类、产地搜索；每页 10 条本地分页；新建与独立详情查询；查看关联批次或为选定产品新建批次。
- 批次：按所属产品、业务状态、上链状态筛选；显示地块、种植/采收日期；新建时继承产品机构，支持可选 JSON 扩展资料。
- 关闭/召回：弹窗确认并填写原因；只对生产中且链状态已确认或未启用的记录开放。已关闭/召回记录保留详情，不提供重新开启功能。
- 表单校验必填、正整数 ID、长度、重复编码、日期先后及 JSON 对象；错误关联字段并将焦点移到首个无效项。连续为同一产品新建批次仍能正确带入机构。
- 保存时防止重复提交；业务保存与链状态分别提示。网络或服务错误导致结果不明时，锁定再次提交，通过 GET「核对保存结果」恢复，不自动重发写请求。
- 原生 `dialog` 提供焦点限制、Escape 关闭、提交期间关闭保护；表格在手机宽度内横向滚动。

## 后端配套

- 编码唯一键冲突返回安全的 HTTP 409，页面保留表单并说明编号冲突。
- 增加产品/批次 ID 正数及字段长度校验；批次机构归属和日期先后在写入前校验。
- 重复关闭/召回已终结批次返回 HTTP 400，在提交链交易前拦截。
- canonical JSON 注册 `JavaTimeModule`，修复包含 `LocalDate` 的批次无法生成摘要的问题；日期文本稳定为 ISO 日期。
- 无数据库结构或合约接口变更。

## 仍待后续阶段

机构当前使用数值 ID，无机构选择 API；列表目前是全量响应上的本地筛选/分页，不是服务端分页。尚无产品编辑/删除、批次重开和写链重试接口。批次并发关闭的全局幂等与异步交易对账仍需后端进一步完善；前端提交保护不能代替服务器并发控制。
