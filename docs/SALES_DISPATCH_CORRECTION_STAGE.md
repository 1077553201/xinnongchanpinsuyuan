# 尚无下游安排的销售出库数量更正

实施日期：2026-10-26。对应 `NEXT-07` 销售履约更正首批；已有运输安排、逐件绑定或冻结流转证据的出库仍保持阻止。

## 入口与适用条件

“销售订单 → 具体订单 → 销售出库记录 → 销售出库更正 / 调整历史”。保留原库存流水及销售出库，另行追加数量调整版本；不通过普通库存更正绕过销售依赖。

本轮仅允许本仓、本包装最近一张销售出库，原订单仍为待出库、部分出库或已全部出库，并满足：

- 本笔没有运输单，连“待发运”的安排也不能直接修改。
- 本笔没有具体包装码关联、逐件收货或冻结的流转证据。
- 本仓本包装没有后续原始库存流水，且原销售明细、包装、仓库与机构一致。

原订单已取消或停止时不能靠更正重新开启履约。生产、质检及其他出库的证据可供核对，不被改写；本笔有依赖时先处理依赖，不能静默覆盖原事实。

## 同步核对的数量与状态

填写核实后的**本笔出库总件数**，不是差额。支持减少、增加及归零，但本明细累计有效出库不能超过订购件数，仓库及来源余额不能为负或超过有效入库量。

更正差额同步影响当前仓库余额、来源台账及订单明细剩余待出库量。订单按所有明细的有效出库重新计算：全为零时待出库，部分完成时部分出库，全部完成时已全部出库。原订购数量、单价、约定金额、客户与更正前出库记录保持原样；不自动退款，不把实物退回当作误录更正。

预览列出本笔原/新数量、本仓余额、累计出库与剩余件数、预计订单状态及关联资料。实际核实人员、核实时间、原因、参考单据、登记账号和前序摘要逐版保存。一个原单最多 100 版；相同确认标识重试不重复写入，库存、订单或依赖变化时须重新预览。

更正先锁订单再锁包装，与正常销售出库和运输创建协调；包装码关联取得包装锁后重新读取有效出库容量。调整插入与订单状态更新在同一事务完成，状态更新失败则回滚。

## 后续运输、包装码与证据

- 库存、销售累计数量、销售出库明细、后续运输及其他更正的关联订单预览统一读取有效数量，重量按原规格计算。
- 销售页同时展示原出库和当前有效出库；归零记录仍保留，但禁用运输及逐件绑定入口，服务端同样拒绝。
- 运输创建取得订单锁后再次读取数量，避免使用锁前旧值。运输安排读取更正后的有效数量；发运时间不能早于原出库及最近数量更正，页面显示该时间依据。
- 一旦存在运输安排，本笔进一步更正即被阻止。已成功的旧请求可以查询重放结果，不能借重放新增调整或重开履约。
- 原单、数量调整和运输分别留档；本地调整摘要不表示已上链，不自动创建包装码、发运事件或链交易。
