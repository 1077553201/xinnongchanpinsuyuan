# 按仓库查看货物

更新时间：2026-10-21。本轮补齐用户反馈的库存查询入口，未推进销售或运输业务。

## 入口

管理台“库存台账”顶部提供“按仓库查看”和“按种植来源查看”。进入“按仓库查看”后，可以从仓库卡片或下拉框选择仓库；原有仓库档案卡片也增加“查看本仓货物”入口。

页面地址为 `/admin/inventory/warehouse`，指定仓库可使用 `/admin/inventory/warehouse/<仓库ID>`。保留原有按周期、包装批次办理的页面。

## 查询与汇总

- 默认显示本仓当前余量大于零的货物，跨地块和种植周期查询，包含已经结束种植的来源，不受原有“最近 200 批包装”列表限制。
- 明细按包装批次展示产品、品种、等级、固定规格、本仓件数和净重、采收与种植来源、最近办理时间。
- 支持搜索产品、品种、地块、等级及包装/采收/种植批次编码；勾选“同时显示本仓已清空的历史批次”可以查询余量为零的历史货物。
- 后端分页支持每页 20、50、100 条，显示总数和页数。搜索按文字匹配，`%` 等字符不会成为通配符。
- 顶部显示本仓全部在库批次数、净重，以及按包装单位分开的件数；箱、袋不混加。汇总不随搜索、分页或已清空开关变化。

只有实际在该仓有库存流水的批次才属于该仓；未入库的包装不会出现在仓库货物列表中，同批放在其他仓的数量也不会计入本仓。

## 来源与办理

点击货物行“来源与出入库”进入原包装台账，携带仓库上下文，显示本仓余量，并在入出库/损耗表单预选该仓。该办理页的汇总仍是本批全部仓库的总台账，页面会明确提示，可点击“返回本仓货物”返回仓库视图。

库存保存时仍按原服务核对最新余量和权限；查询结果与默认选择不会替代保存校验。新视图只提供查询和办理入口，不自动新增流水。

## 权限与验证

新增查询接口为 `GET /api/production/warehouses/{id}/stock`，支持 `search`、`includeEmpty`、`page`、`pageSize`。后端先核对仓库所属机构，再在同一读取快照中查询汇总、总数及本页货物；管理员可跨机构，只读人员可读本机构，其他机构访问会被拒绝。

无需数据库迁移，本轮仅从已有库存流水计算仓库视图。

- 后端 128 项测试通过，新增 8 项仓库查询权限、分页及搜索范围测试；前端 27 项已有测试及类型检查、构建通过。
- 真实接口用专门的 QA 仓库验证 202 批在库货物跨页完整可查、跨周期来源、分仓隔离、箱/袋分类汇总、已清空批次、空仓、文字搜索及越权拒绝。
- 浏览器验证两种视图入口、翻页、搜索、切仓、清空历史、带仓库上下文的出库表单、只读访问和两套主题；320、390、768、1024、1920px 无整页横向溢出，运行异常为零。

测试标识为 `QA-WH-STOCK-*`，不代表实际经营货物；证据位于忽略目录 `.workbuddy/preview/warehouse-stock/` 与 `.workbuddy/preview/warehouse-stock-browser/`。设备反馈继续保留在待优化清单，库存本身的业务边界仍见 [库存台账阶段记录](INVENTORY_LEDGER_STAGE.md)。
