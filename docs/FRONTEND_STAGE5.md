# 前端第 5 阶段：IoT 与 NFC 管理

日期：2026-10-20。

## IoT

`/admin/iot` 提供网关/设备登记、读数及趋势、窗口摘要、告警、模拟上报和手动聚合。按网关、设备、指标筛选，明确最近 100 条范围；MQTT 是否启用和实际连接分别由后端 `/api/iot/status` 返回，不凭 EMQX 已部署推断消费成功。

补齐 IoT 时间文本解析。读数查询支持仅设备、仅指标或二者组合。自动聚合按批次隔离；手动窗口包含多个批次时拒绝混合。窗口身份包含数据摘要，更新快照不会重复使用已经上链的窗口 ID；相同快照仍按哈希幂等复用。公众查询每个时间窗只取最新版本，每个设备/指标显示最新窗口，避免重复统计。

## NFC

`/admin/nfc` 显示最近最多 200 条标签和交易状态，支持一次绑定及停用确认。补齐列表/详情查询；后端拒绝已有绑定的单品再次绑定、已停用标签重复停用；单品与公众页同步停用状态。原始 UID 不在查询列表返回。

当前合约与页面没有标签换绑、恢复及动态防克隆能力；普通 UID 关联不代表物理标签可信。绑定和停用的失败/禁用状态按真实交易记录展示，不自动重发。

## 运行边界

Agent 当前启动的后端临时启用了 MQTT，读取现有 `.env` 的 broker 配置，连接已验证。以后可用 `scripts/Start-Backend.ps1 -EnableMqtt` 启动。设备签名尚未验签，状态/事件 topic 仍主要记录日志；没有告警处理和设备控制写接口。自动聚合保留快照版本，长期运行的写链频率和归档策略需另行优化。
