# 未出库销售订单的停止与替代

实施日期：2026-10-26。对应 `NEXT-07` 销售更正首批；已出库、运输及逐件交付的更正仍未开放。

## 业务入口与范围

“销售订单 → 查看订单与出库 → 更正影响 / 替代历史”。同机构只读账号可查看关系及履约依赖；确认操作需要业务写入权限。

仅原单仍为 `OPEN`（待出库）、实际销售出库笔数为 0、且没有既有替代单时，可以停止原单并创建替代单。本轮固定原包装与仓库的明细集合，可更正客户、联系方式、地址、实际下单日期、数量、单价和说明；不添加、删除或更换货物来源。订购数量受真实包装量限制，人民币金额按精确小数计算，不自动舍入单价。

部分出库、全部出库、已取消、已停止的订单均保持阻止。判断使用全部实际出库笔数，不依赖页面最近记录；同时列出运输单及逐件关联/核对数量。超过 200 笔时依赖详情仅展示前 201 笔并明确提示，禁止执行的判断仍覆盖全部记录。

## 预览与确认

预览冻结原订单、原明细、实际出库与交付依赖、更正原因及替代内容，展示新旧客户、数量、约定金额和当前库存参考。下单不预占库存，库存不足参考不等同于本次实际出库失败；实际履约仍须另行校验。

确认后在**同一事务**内停止原单、创建新订单并保存唯一替代关系。原单转为已取消，保留原客户、数量、金额和原始登记，停止原因引用替代单编码；新单为待出库，从新单继续安排履约。不创建库存流水、不退库、不退款、不发运，也不自动提交链交易。

锁定原订单后按包装 ID 升序获取包装锁，再重新预览核对；与正常销售出库及库存更正协调。订单、库存参考或替代内容变化时要求重新确认；已使用的新订单编码/确认标识不能绑定既有订单充当替代单。一个原单最多一个直接替代单，一个新单最多一个直接来源；新单以后仍可通过同样规则继续更正，形成可追溯关系。

相同确认内容重试返回既有结果，不重复停单或建单；更换内容不能复用旧标识。已成功确认后，即使替代单后来履约，也不重新执行业务。原单影响快照及关系摘要留档，读取时校验，禁止静默改写历史。

## 页面表现与信息边界

新旧订单都可以查看替代关系、原因、登记人和时间，并互相跳转。被阻止的订单不显示可执行表单；预览有冲突时不开放确认。确认前的内容固定，返回后刷新并生成新的确认标识。

客户、联系方式、地址及留档快照仅供有权账号查看，不加入公众溯源页，不发送模型服务。业务替代不改变包装身份、生产/流转/质检证据，不把本地关系摘要显示成链上验证。
